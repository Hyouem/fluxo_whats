# 🦷 Sorriso Prime Dentistry — WhatsApp Flow Automation

Conversational automation system for a dental clinic, developed with a focus on user experience, flow organization, and scalable WhatsApp customer service structure.

---

## 📌 About the Project

This project simulates a complete automated customer service flow for a dental clinic, guiding patients from the first contact to the final appointment scheduling.

The structure was built using node-based conversational logic, allowing multiple service branches according to the patient's needs.

---

## ⚙️ Features

✅ Automated WhatsApp service  
✅ Structured conversational flow  
✅ Conditional branching  
✅ Appointment scheduling simulation  
✅ Emergency priority flow  
✅ Scalable structure for new services  
✅ Node and edge based architecture

## 🧠 Flow Structure

The system uses an architecture based on:

- Nodes → service steps
- Edges → connections and transitions
- Options → user decisions
- Dynamic variables → name, date, and schedule

Example:

```json
{
  "from": "node_edz0xpymk",
  "to": "node_411oeq7f5",
  "option_index": 1
}
```
